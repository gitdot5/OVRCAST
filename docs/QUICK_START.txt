OVRCAST 0.4.1 — Public preview

Your AI capacity, at a glance.
Created by Git. Free and open source under the MIT license.

1. Unzip the download, drag OVRCAST into Applications, then open it.
2. In Settings → Connect, confirm Built-in collector ready. Choose a provider.
3. Complete sign-in through the official provider software, then choose
   Check connection and Open my board.

No separate CodexBar installation is required. OVRCAST includes its own
maintained collector derived from CodexBar’s MIT source. Provider accounts and
provider apps/CLI connections are still required. Connect Claude may open
Claude Code login in Terminal; missing Claude Code opens its setup instructions.

Click the pin to keep the board open. Drag its title bar to move it.
Command-Shift-U shows or hides the board. The eye button turns on privacy mode.
Settings contains aliases, notifications, quiet hours and computer connections.

To add another Mac, install OVRCAST there and use an existing trusted SSH
alias in Computers. OVRCAST does not configure Remote Login or SSH keys.
Both apps must be running to keep their snapshots fresh.

Download OVRCAST-0.4.1-macOS.zip from the official GitHub release. It is signed under
Du Nguyen Tran's Developer ID and notarized by Apple. Older preview artifacts
are separate builds. Do not disable macOS security to install software.

OVRCAST is free and MIT licensed. Original source and license notices are
included in the source distribution. Provider services may have their own fees.

Official download: https://github.com/gitdot5/OVRCAST/releases/tag/v0.4.1
Test scope and limitations: docs/RELEASE_REVIEW.md in the source distribution.

Account cards show the next provider-reported usage reset, including the window,
countdown and exact local date/time with time zone. Open an account for each
reported quota schedule. Missing reset times stay unavailable; a passed reset
waits for a new provider reading before confirming allowance.

Claude usage requires a Claude Code OAuth connection. A Claude Desktop sign-in
alone may not supply it. Connect Claude, complete sign-in, then check again.
CodexBar-specific token-account configuration is not automatically imported.

Updates are manual: download a newer OVRCAST release and replace the app in
Applications. Existing UsageBoard storage paths and settings remain compatible.

Privacy mode keeps Mac types visible while hiding custom computer names.
Your local Mac type is detected from macOS. Two of the same type receive
numbered labels, such as MacBook Pro 1 and MacBook Pro 2.
