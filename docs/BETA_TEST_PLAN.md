# OVRCAST 0.5.0 opt-in beta

Status: prepared; no participants enrolled or contacted. This plan is not beta
acceptance evidence. Keep publication held until the required checks are complete.

Start with 5–10 volunteers using their own accounts. Cover Codex, Claude Code
OAuth and Antigravity, different provider plans, Apple Silicon and Intel, and
macOS 14 plus newer versions. Each person installs the signed candidate and
keeps their existing provider credentials on their own Mac. Never request tokens,
SSH keys, passwords, raw snapshots or screen recordings containing account data.

## Session checklist

1. Clean install: verify the Developer ID/notarization, choose a provider, complete
   sign-in directly and receive a current usage reading. Record time to first
   reading and whether the instructions were sufficient.
2. Upgrade: retain privacy, aliases and computer settings. Exercise cancellation,
   signed update installation/restart and manual recovery to the previous release.
3. Recovery: disconnect/reconnect the network, sleep/wake, make a remote Mac
   unavailable, and reconnect an expired provider session. Check stale labels,
   independent results, automatic retry and recovery without duplicated accounts.
4. Alerts: opt in through macOS, send a test notification, then verify quiet hours,
   snooze and one real threshold/reset event. Record Focus settings separately.
5. Accessibility: use keyboard alone and VoiceOver; check named controls, selected
   provider state, privacy state, Reduce Motion, contrast and small-screen scrolling.
6. Endurance: leave the app running overnight through at least one reset and
   sleep/wake cycle. Record crashes, missed refreshes, memory growth and battery
   observations. Do not count an accelerated fixture run as overnight evidence.

## Feedback and acceptance

Use participant labels such as B01, not account identities, in the shared ledger.
Record only app build, macOS major version, processor family, provider, scenario,
result and reproduction steps. Participants may preview and share OVRCAST's safe
support report. Sharing is optional; nothing is collected automatically.

A scenario passes only with observed results and an identified build. A blocked
permission prompt, pending sign-in or missing hardware remains pending. Fix and
retest reproducible issues. Require all critical scenarios, no unresolved crash or
privacy regression, and explicit review of remaining findings before publication.
